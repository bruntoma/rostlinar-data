# Rostlinář - balíčky fotek

Fotky rostlin, které si aplikace Rostlinář (offline atlas léčivých, jedlých a planých
rostlin) stahuje na přání uživatele. Jsou v [releasu `packs`](../../releases/tag/packs)
jako zipy; aplikace ověřuje jejich otisk (sha256), proto se soubory nemažou ani nepřepisují.

## Licence

Fotky pocházejí z [Wikimedia Commons](https://commons.wikimedia.org/) a byly zmenšeny
a převedeny do formátu WebP. Každá má vlastního autora a licenci (CC BY, CC BY-SA, CC0 nebo
volné dílo). Ty jsou v souboru `AUTORI_A_LICENCE.txt` uvnitř každého zipu a aplikace je
zobrazuje pod každou fotkou.
